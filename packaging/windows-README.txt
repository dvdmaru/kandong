看懂 KanDong — Windows 版
=========================

影片沒中文字幕？一看就懂。
看懂會在原文字幕下方自動加上台灣繁中譯文；沒有字幕的片，先用語音辨識聽寫出字幕再翻譯。
播你自己的影片檔，不提供影片、不下載字幕。翻譯在你自己的電腦上跑，影片和字幕不會上傳到任何地方。

【三步開始】
1. 把整個 KanDong 資料夾解壓到任何地方（桌面、D 槽都可以）。
2. 雙擊「看懂」，會開出播放器，把影片拖進去就開始播。
3. 第一次還沒有翻譯模型：在播放器按右鍵 → 設定 → 翻譯模型與伺服器，點「下載」，下載好就自動開始用。
   （也可以雙擊「一鍵下載模型」，或照 models 資料夾裡「把模型放這裡.txt」的連結自己下載後放進 models 資料夾。）
   （也可以直接把影片拖到「看懂」上。）

【第一次雙擊可能看到的畫面】
- 「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。看懂是開源軟體但沒有花錢買數位簽章，所以 Windows 不認得它。
- 說缺少「Visual C++ 可轉散發套件」：照畫面開的微軟官方頁面，下載 X64 版安裝後再雙擊「看懂」。

【電腦需求】
- 64 位元 Windows 10／11。
- 記憶體 16GB 用標準模型；8GB 用輕量模型。有獨立顯示卡會快很多。
- 翻譯引擎、語音辨識引擎都已經內附在 engine 資料夾，不必另外安裝。

【操作】
  滑鼠右鍵    選單（播放、字幕、音訊、翻譯、倍速、設定）
  滑鼠移到下方 控制列（播放、進退、倍速、字幕、音軌、翻譯開關、全螢幕）
  Ctrl+t      翻譯開／關
  ← / →       退 5 秒／進 5 秒；Shift+← / → 退 30 秒／進 30 秒
  1 – 5       倍速 0.5x／1x／1.5x／2x／3x（變速不變調）
  D / A / S   加速 10%／減速 10%／回到 1x
  ↑ / ↓       音量 ±5%
  = / -       字幕放大／縮小
  v           隱藏原文字幕（只看譯文）
  空白鍵 暫停；f 全螢幕；q 離開

【常見問題】
- 左上角出現「翻譯伺服器連線失敗」：用「看懂」啟動（不要直接開 mpv.exe），它會先把翻譯引擎開好。
- 換模型、下載模型、用自己的 GGUF 模型：右鍵 → 設定 → 翻譯模型與伺服器。
- 翻譯引擎啟動失敗：多半是記憶體不夠，在上面那個選單換成輕量模型；詳細記錄在 logs 資料夾。
- 沒字幕的片：需要先下載語音辨識模型（同一個選單）。開 2 倍速以上若出現「語音辨識跟不上」，按 S 回 1x。
- 翻好的譯文存在影片旁邊（<影片名>.ft.zh-TW.json／.srt），重看不必再翻。

【不想下載模型：改用雲端 API（OpenAI／Claude／Gemini）】
先到 OpenAI、Anthropic 或 Google AI Studio 後台複製 API 金鑰，再到
右鍵 → 設定 → 翻譯模型與伺服器 →「連到雲端 API 或其他翻譯伺服器」點那一家，選推薦的模型即可。
要自己的金鑰、按用量付費（兩小時的片估計約 0.1–0.2 美元），字幕會送到那一家。
金鑰用 Windows 的加密功能存在這台電腦（%APPDATA%\KanDong\keys），不放在看懂資料夾裡。
同一個選單可以「刪除這台電腦存的 API 金鑰」或「改回這台電腦內建的翻譯模型」。

【進階：用 Ollama、LM Studio，或翻譯引擎放在區網另一台電腦】
右鍵 → 設定 → 翻譯模型與伺服器 →「連到雲端 API 或其他翻譯伺服器」，選好模型會先翻一句測試，成功才改用。
這時「看懂」就不會在本機開翻譯引擎。語音辨識的伺服器（asr_endpoint）目前要手動改
portable_config\script-opts\floattranslate.conf。

【這個播放器刻意不做的事】
不提供影片、不下載字幕、不攔截串流、不破解 DRM（Netflix 等串流平台不支援）。
