看懂 KanDong — Mac 版
=====================

影片沒中文字幕？一看就懂。
看懂會在原文字幕下方自動加上台灣繁中譯文；沒有字幕的片，先用語音辨識聽寫出字幕再翻譯。
播你自己的影片檔，不提供影片、不下載字幕。翻譯在你自己的 Mac 上跑，影片和字幕不會上傳到任何地方。

【需要】
- Apple 晶片（M1 以後）的 Mac；記憶體 16GB 用標準模型，8GB 用輕量模型。
- Homebrew（https://brew.sh）。裝好後在 Terminal 貼上這一行，只要做一次：
    brew install mpv ffmpeg llama.cpp whisper-cpp

【三步開始】
1. 把 KanDong 資料夾放在任何地方（例如「應用程式」或「文件」）。
2. 雙擊「看懂.command」，會開出播放器，把影片拖進去就開始播。
3. 第一次還沒有翻譯模型：在播放器按右鍵 → 設定 → 翻譯模型與伺服器，點「下載」，下載好就自動開始用。
   （也可以雙擊「一鍵下載模型.command」，或照 models 資料夾裡「把模型放這裡.txt」的連結自己下載後放進 models 資料夾。）

第一次雙擊 .command 若被擋（「無法打開，因為它來自未識別的開發者」）：
在 Finder 對它按右鍵 →「打開」→ 再按一次「打開」，之後就能直接雙擊。

【操作】
  滑鼠右鍵    選單（播放、字幕、音訊、翻譯、倍速、設定）
  滑鼠移到下方 控制列（播放、進退、倍速、字幕、音軌、翻譯開關、全螢幕）
  Ctrl+t      翻譯開／關
  ← / →       退 5 秒／進 5 秒；Shift+← / → 退 30 秒／進 30 秒
  1 – 5       倍速 0.5x／1x／1.5x／2x／3x（變速不變調）
  D / A / S   加速 10%／減速 10%／回到 1x
  ↑ / ↓       音量 ±5%
  = / -       字幕放大／縮小
  v           隱藏原文字幕（只看譯文）
  空白鍵 暫停；f 全螢幕；q 離開

【常見問題】
- 換模型、下載模型、用自己的 GGUF 模型：右鍵 → 設定 → 翻譯模型與伺服器。
- 翻譯引擎啟動失敗：多半是記憶體不夠，在上面那個選單換成輕量模型；記錄在 ~/Library/Logs/KanDong。
- 沒字幕的片：需要先下載語音辨識模型（同一個選單）。
- 翻好的譯文存在影片旁邊（<影片名>.ft.zh-TW.json／.srt），重看不必再翻。
- 不想下載模型、改用雲端 API（OpenAI／Claude／Gemini）：先到那一家後台複製 API 金鑰，再到同一個選單的
  「連到雲端 API 或其他翻譯伺服器」點那一家。按用量付費、字幕會送到那一家；金鑰存在 Mac 鑰匙圈，不放在看懂資料夾。
- 用 Ollama、LM Studio 或區網另一台電腦的翻譯服務：同一個選單的「連到雲端 API 或其他翻譯伺服器」。
  設定檔在 ~/.config/kandong/mpv/script-opts/；這時「看懂」就不會在本機開翻譯引擎。

【這個播放器刻意不做的事】
不提供影片、不下載字幕、不攔截串流、不破解 DRM（Netflix 等串流平台不支援）。
