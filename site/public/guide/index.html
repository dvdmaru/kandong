圖文教學

第一次用看懂，三步就能看

下載、拿翻譯模型、雙擊「看懂」。模型只要拿一次，之後每次都是雙擊就看。下面的畫面都是示意圖。

我用 Windows 我用 Mac

WindowsWindows 10／11

1

下載、解壓

到首頁按「下載 Windows 版」，在下載的 zip 上按右鍵 →「全部解壓縮」，放在桌面或 D 槽都可以。

打開資料夾，你會用到的只有兩個：「一鍵下載模型」和「看懂」。

第一次才會遇到

跳出「Windows 已保護您的電腦」？

看懂是開源軟體，但目前沒有數位簽章，因此可能出現這個提示。按「其他資訊」，再按「仍要執行」；是否再次提示依系統狀態而異。

擔心安全的話，原始碼都在 GitHub 上，可以自己檢查。

2

拿翻譯模型（只要一次）

模型就是「翻譯的大腦」，檔案比較大，所以沒有直接包進下載檔。兩種拿法選一種：

A. 一鍵下載（最簡單）

雙擊「一鍵下載模型」，輸入編號按 Enter。會從 Hugging Face 官方下載、放進 models 資料夾、自動檢查檔案。中斷了再雙擊一次會接著下載。

===== 看懂：一鍵下載模型 ===== 這台電腦記憶體約 16 GB，建議選 1（標準）。 [1] 翻譯模型・標準（約 4.6GB） [2] 翻譯模型・輕量（約 1.1GB） [3] 語音辨識模型（約 574MB） 輸入要下載的編號：13

示意圖：輸入 13 ＝標準翻譯模型＋語音辨識模型一起下載

B. 自己下載（想先確認來源）

用瀏覽器點下面的連結下載，檔案直接放進 KanDong 裡的 models 資料夾，檔名不要改。

模型大小什麼時候選
翻譯・標準4.6GB記憶體 16GB 以上
翻譯・輕量1.1GB記憶體 8GB、電腦較舊
語音辨識574MB只有看沒字幕的片才需要

完整檔名與 SHA256 校驗碼在 models 資料夾的「把模型放這裡.txt」。

3

雙擊「看懂」，把影片拖進去

會先出現一個黑色視窗把翻譯引擎開好（載入時間依電腦而異），接著播放器出現。把影片拖進播放器，或一開始就把影片拖到「看懂」上。

看片時黑色視窗不要關；關掉播放器時，它會自動把引擎收掉。

MacMac（Apple 晶片）

0. 先裝工具（一次）

裝好 Homebrew 後，打開「終端機」貼上：

brew install mpv ffmpeg llama.cpp whisper-cpp

1. 解壓、拿模型

解壓 KanDong-mac.zip，雙擊「一鍵下載模型.command」選編號；或照上面 B 的連結自己下載，放進 models 資料夾。

2. 雙擊「看懂.command」

第一次若被擋（來自未識別的開發者）：在 Finder 對它按右鍵 →「打開」→ 再按「打開」，之後就能直接雙擊。

遇到問題

說缺少「Visual C++ 可轉散發套件」

翻譯引擎需要微軟的這個元件。照畫面開的微軟官方頁面，下載 X64 版（vc_redist.x64.exe）安裝，再雙擊「看懂」。

翻譯引擎沒有成功啟動

先查記憶體與模型檔是否完整；可改用輕量模型（一鍵下載選 2）。兩個翻譯模型都放的話，記憶體 12GB 以上會自動用標準版。詳細記錄在 logs 資料夾（Mac 在 ~/Library/Logs/KanDong）。

左上角出現「翻譯伺服器連線失敗」

請用「看懂」啟動，不要直接開 mpv.exe：「看懂」會先把翻譯引擎開好。

沒字幕的片沒有出現字幕

需要語音辨識模型（一鍵下載選 3）。聽寫與翻譯完成後才會出現字幕；若出現「語音辨識跟不上」，按 S 回 1x。

還是不行？

到 GitHub Issues 開一則，附上作業系統、影片格式、畫面上的訊息，和 logs 資料夾裡的記錄。
