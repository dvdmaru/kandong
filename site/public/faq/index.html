看懂常見問題：模型怎麼選、字幕沒出現與人名音譯

重點速答

選模型先看記憶體；沒字幕的片還需要語音辨識模型。看懂處理本機影片，常見卡關包括選錯字幕類型、引擎未啟動，以及人名被音譯。

8GB／16GB 記憶體，各選哪個模型？

依 README 建議：8GB 或較舊的電腦選 Hy-MT2 1.8B 輕量模型，16GB 以上選 7B 標準模型。模型檔分別約 1.1GB、4.6GB；這是檔案大小，不是整套程式的記憶體用量。

README 的實測條件是 Apple M4／16GB、含 12 句前文：7B 每句約 1–1.5 秒，1.8B 約 0.25 秒。這些結果不能推算成其他硬體或整部影片的處理時間。

要先減輕負擔，可從輕量模型開始；想用標準模型，仍需看其他程式占用的記憶體。查看 README 的模型與實測說明。

Hy-MT2 是什麼？能直接聽影片嗎？

Hy-MT2 是騰訊（Tencent）公開的多語翻譯模型。看懂用它把原文字幕翻成台灣繁中；聽音訊轉文字則由 whisper.cpp 負責。沒字幕的影片需要兩種模型，不能只準備翻譯模型。

騰訊官方標準模型卡、輕量模型卡。

為什麼按「模型」選單不能切換？

目前「模型」選單只是預告。換模型要調整 models 資料夾裡的模型檔；兩個翻譯模型都在時，啟動器會依記憶體自動挑選。若要固定用輕量模型，先把標準模型移出 models，關閉後再重新啟動看懂。

人名會保留原文嗎？換大模型能解決嗎？

不保證。Hy-MT2 常把人名音譯，例如 Marcus 變成「馬庫斯」；換大模型也可能發生。譯名修正還在規劃中。

支援哪些電腦？可以看 Netflix 嗎？

下載包提供 Windows 10／11（64 位元）與 macOS Apple 晶片版；Mac 需要先裝 Homebrew 工具。看懂只處理本機影片檔，不支援 Netflix 等串流平台，不攔截串流，也不破解 DRM。

影片和字幕會上傳嗎？需要一直連網嗎？

預設本機設定下，翻譯與語音辨識在自己的電腦執行，影片和字幕不會送到雲端翻譯服務；取得軟體、工具和模型仍需要網路。進階設定若把伺服器指向區網另一台電腦，字幕或聽寫用音訊就會送到那台電腦處理，因此本機處理的前提也會改變。

影片看得到字幕，為什麼還要語音辨識模型？

看得到的字可能是 PGS 等圖形字幕，或已燒錄在影像中。看懂不做 OCR；沒有可用文字軌時，改從聲音聽寫再翻譯。先看 MKV 字幕類型的分辨方式。

出現「翻譯伺服器連線失敗」怎麼辦？

先確認是用「看懂」啟動器開啟，而非直接開播放器執行檔。啟動器會先準備翻譯引擎；若仍失敗，再查模型檔、啟動畫面與 logs 記錄。

語音辨識跟不上，字幕一直空白怎麼辦？

先按 S 回到正常播放速度，確認 Whisper 語音辨識模型已備妥，再讓聽寫繼續。播放超過處理進度或跳轉到未處理段落時可能空白；完整步驟見沒字幕影片聽寫教學。

翻好的字幕在哪裡？是雙語 SRT 嗎？

繁中快取在影片旁的 <影片名>.ft.zh-TW.json，完整翻譯後才輸出 .ft.zh-TW.srt；完整聽寫另可存成 .ft.asr.srt。這份 SRT 只有繁中譯文；原文與譯文一起出現的雙語畫面，是播放時在看懂裡疊出來的。
